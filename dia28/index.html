Eventos Comunes de JavaScript

click

Se dispara cuando el usuario hace clic con el ratón sobre un elemento.

mouseover

Se dispara cuando el puntero del ratón se mueve sobre un elemento.

keydown

Se dispara cuando el usuario presiona una tecla.

submit

Se dispara cuando se intenta enviar un formulario. Útil para validación.

change

Se dispara cuando el valor de un elemento (como input, select, textarea) ha cambiado y el elemento pierde el foco (blur).

input

Se dispara inmediatamente cuando el valor de un elemento de formulario cambia (a diferencia de 'change').

focus

Se dispara cuando un elemento recibe el foco.

blur

Se dispara cuando un elemento pierde el foco.

load

Se dispara cuando un recurso (ej. imagen, o la página entera) ha terminado de cargarse.

resize

Se dispara cuando la ventana del documento cambia de tamaño.

scroll

Se dispara cuando el documento o un elemento ha sido desplazado.

contextmenu

Se dispara cuando el usuario intenta abrir el menú contextual (normalmente con clic derecho).

dblclick

Se dispara cuando el usuario hace doble clic sobre un elemento.

mousedown

Se dispara cuando se presiona un botón del ratón sobre un elemento.

mouseup

Se dispara cuando se suelta un botón del ratón sobre un elemento.

mousemove

Se dispara cuando el puntero del ratón se mueve (muchas veces por segundo).

mouseout

Se dispara cuando el puntero del ratón sale de un elemento y de sus hijos.

mouseenter

Se dispara cuando el puntero del ratón entra en un elemento (no se dispara en los hijos).

mouseleave

Se dispara cuando el puntero del ratón sale de un elemento (no se dispara en los hijos).

transitionend

Se dispara cuando una transición CSS ha finalizado.
